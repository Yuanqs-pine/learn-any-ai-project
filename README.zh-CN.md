# learn-any-ai-project

**通用 AI 项目学习引擎** —— 一份单文件、自包含的 Agent 技能，教你从零系统学会**任意主流 AI 项目**（RAG / Agent / LLM 应用 / CV / 语音 / 多模态 / AIGC / 推荐系统 / 传统 ML 与 NLP / LLM 微调 / AI 数据工程 / 模型服务与 AI 平台基建 / AI 测试评测），不绑定任何具体项目。

> English overview: [README.md](./README.md)

**一句话核心**：不给你固定的课程大纲，而是从第一性原理按目标项目自身画像推导章节化学习计划（**LEARN.md**）——章节数量、主题与顺序由项目决定，绝不套模板。学习过程由评审门、逐章生成 + 本地绿条验证、`.engine/state.json` 账本双向状态同步、以及以盲测收尾的手动实践驱动——**「学会了」= 你自己能跑通，而不是 Agent 跑通了。**

---

## 为什么需要这份技能

市面上的"学 AI 项目 X"教程都是某一项目的专属教材——换个类型、换个技术栈、换个阶段，章节就对不上了。本技能是**方法论引擎**：它只问"要真正理解眼前这个系统，必须依次走通哪些闭环（环）？"，把环折叠成章节，渲染出一份与项目实际结构吻合的手册。技能内部**零项目内容**：没有路径、没有文件名、没有工具栈、没有技术商标——拷进任何仓库都成立，放上 GitHub 共享也安全。

## 核心特性

| 特性 | 含义 |
|---|---|
| **零项目依赖** | 不引用任何具体项目；开源、闭源被测对象均可学习 |
| **第一性原理推导章节** | 章节数/主题/顺序由项目画像决定，不由模板决定（内置防复制检查） |
| **覆盖主流 AI 类型** | §5.3 分层索引为 15+ 类型提示差异化核心环；未命中/新形态同样适用——方法有效性从不依赖命中表 |
| **评审门** | 写任何代码前的人机硬关卡——先由你审阅确认学习计划 |
| **状态账本与双向同步** | `.engine/state.json` 为唯一事实源；文档状态卡只是投影；sha256 漂移自动判 `verified → dirty` |
| **手动优先学习** | 每章内嵌手动点（X.6）；起服务/装依赖/执行命令由**你亲手完成**，Agent 只讲解与验证；收官**盲测**证明能独立交付 |
| **产物精简纪律** | 代码最小够用、产物干净（临时文件即清）、无「XX版」字样、零废话——产出的文档/代码就是可交付资产 |
| **语言跟随用户** | 对话与全部产物按你当前使用的语言书写（中文/英文…），无硬编码；专有名词与命令保留原文 |
| **双语规范** | `SKILL.md`（中文，权威版）+ `SKILL.en.md`（英文，1:1 对照），由 `docs/terminology.md` 术语契约约束 |

## 快速开始

### 1. 给 Agent 安装技能

把 `skills/learn-any-ai-project/SKILL.md` 复制（或建软链）到你的 Agent 技能目录，例如 `~/.workbuddy/skills/learn-any-ai-project/SKILL.md`，然后重载 Agent 即可。英文用户用 `SKILL.en.md`（同一技能、同一套规则）。

> 两个文件均为自包含单文件：无额外脚本、无附属资源。也可以直接把文件放到项目仓库旁就地引用。

### 2. 开始学习你的第一个 AI 项目

在你想学的项目目录里：

1. 说："系统地学习这个项目"（触发词均可："为项目生成学习计划""按学习手册风格建学习文档"）。
2. 技能执行 **S0 画像**：先探测项目目录，再问你几个问题（类型/规模/技术栈/阶段/学习目标/环境约束/共享要求/产出语言）。
3. 从第一性原理推导章节地图，在项目根渲染出 **LEARN.md**。
4. **写代码前先过评审门**：你审阅并确认，章节不合适可以调整。
5. 随后逐章推进（S3 → S4 → S5）：先环境章（守护类/GUI 服务由你亲手启动），每章走 生成 → 本地绿条验证 → 手动点 → 状态同步。
6. 收官做**盲测复现**：隐藏全部命令，你独立把最小链路完整跑通。过了，才算真正学会这个项目。

### 3. 技能运行时只创建两样东西

| 条目 | 位置 | 用途 |
|---|---|---|
| `LEARN.md` | 目标项目根 | 章节化学习手册（版式按技能 §6） |
| `.engine/state.json` | 目标项目根 | 运行时自动创建的账本——章/产物状态的唯一事实源；技能本身从不携带账本 |

除此之外什么都不留：无教学垃圾、无临时文件残留。

## 工作流（S0–S5）

```
S0 画像 ──► S1 拆环推导 ──► S2 渲染 LEARN.md ──► [评审门] ──► S3 环境就位
                                                                │
                 S5 收官验收 ◄── S4 逐章循环（对齐 → 生成 → 验证 → 同步 → 收尾）
                 (+ 盲测复现)
```

- **S0 画像**：探测 + 询问 9 个维度（类型/规模/技术栈/阶段/学习目标/交付形态/环境约束/共享要求/语言）。
- **S1 推导**：7 问清单找出环；折叠规则把环变章节；§5.3 分层索引按项目类型提示方向；防复制检查兜底。
- **S2 渲染**：LEARN.md 锁「外形」（身份头含画像摘要+进度总表+阅读导航、章骨架 X.1–X.6 统一）不锁「内容」。
- **评审门**：7 条标准全部满足才放行——生成任何代码前必须用户确认。
- **S3 环境**：手动强度最高的章——依赖安装、服务启动由你亲手完成；Agent 兜底实测最小连通。
- **S4 循环**：对齐 → 生成/讲解 → **双轨验证**（Agent 绿条自证 + 你亲手执行，两者输出一致才通过）→ 账本同步 → 口头复述。
- **S5 验收**：收官验收 + 盲测复现 + 产物干净全项目复检。

## 覆盖的项目类型（§5.3 索引）

| 层 | 类型 |
|---|---|
| 应用层 | LLM 文本应用、RAG 知识库问答、Agent、CV 应用、语音应用、多模态应用、AIGC 生成工具、推荐系统 |
| 模型层 | 传统 ML 与 NLP 流水线、LLM 微调与对齐训练、AI 数据工程 |
| 平台层 | 模型推理/服务平台、AI 网关与可观测平台、低代码 AI 应用平台 |
| 质量层 | AI 测试与评测工程（横切以上各层） |

表中未列出的类型（含新形态）同样走同一套推导流程——**方法有效性从不依赖命中本表**。开源与闭源目标均支持（白盒加"源码走读"环；黑盒换成"读文档/调 API/探针实验"环）。

## 设计原则（详见 SKILL §1）

零项目依赖 · 内容定制、形式统一 · 第一性原理 · 状态单一事实源（账本）· 轻量自包含 · 学习即产出 · 手动优先（练手≥演示）· 内容零版本零废话 · 产物精简与干净 · 语言跟随用户。

## 术语契约

`SKILL.md` 与 `SKILL.en.md` 在 [docs/terminology.md](./docs/terminology.md) 的翻译契约下保持 1:1 同步——一个中文概念只对应一个固定的英文术语。扩展技能时：先改中文权威版，再按契约表在英文版中镜像同步。
